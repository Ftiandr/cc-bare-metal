  cc::chdir(dir)  cc::cwd()  cc::pid()  cc::sleep(seconds)

TERMINAL
  cc::tty::size() -> {cols, rows}     the GUI resizes it (term_resize event)
  cc::tty::Mode raw(CC_TTY_RAW | CC_TTY_NOECHO);   restored when it ends
  Output understands ANSI escapes (colours, cursor, ESC[?1049h ...).

EVENTS (CC style)
  cc::setProcessFlags(CC_PROC_EVENTS | CC_PROC_INPUT)   receive events

  cc::startTimer(0.5) -> id, then a "timer" event

NETWORK (man net) - stream sockets between computers, by hostname and port
  int fd = cc::net::connect("base", 1234, 10000);  // fd, or -ECONNREFUSED -ETIMEDOUT
                                                   // -ENETDOWN -EADDRINUSE
  int l = cc::net::listen(1234); int c = cc::net::accept(l);   // a server
  read/write/close the fd; cc::net::sendAll(fd, p, n); cc::net::shutdown(fd)
  cc::waitAny({fd, 0}) waits for sockets, pipes, the terminal and events at once
  cc::net::info(fd) -> {state, local, localPort, remote, remotePort}
  cc::net::status() -> {hostname, channel, sockets (/proc/net/ccnet)}
  cc::net::channel(name); interfaces: /sys/class/net
  C: cc_net_listen cc_net_accept cc_net_connect cc_net_shutdown (0 or errno)
  Packets (for Lua computers that want to talk too): a table
    {ccnet=1, t="syn"|"synack"|"data"|"ack"|"fin"|"rst", src=NAME, sport=PORT,
     dst=NAME, dport=PORT, id=CONNECTION, hid=SENDER-ID, seq, ack, win, data}
  sent on the destination's channel (cc::net::channel(dst): FNV-1a of the
  lower-case name, 100 + h % 60000) with the sender's channel as reply channel.
  seq/ack count bytes (fin takes one), win is the free receive buffer.
