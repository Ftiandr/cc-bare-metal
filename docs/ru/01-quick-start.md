# 1. Быстрый старт и окно компьютера

## Первый запуск

1. Скрафтите WASM-компьютер (рецепт — в [разделе 2](02-blocks.md)) и поставьте его.
2. ПКМ по блоку открывает окно. Выключенный компьютер включается клавишей **Enter** (или пробелом) либо кнопкой
   питания на боковой панели слева.
3. При первом включении установщик спросит имя компьютера, ваше имя пользователя и пароль (и, по желанию, пароль
   root — если его не задать, root работает через `sudo`). Затем войдите под своим именем — появится приглашение
   `имя@компьютер:~$`. Дальше — обычная Unix-подобная консоль:

```sh
help                     # встроенные команды оболочки и синтаксис
man intro                # обзор системы
ls /bin                  # команды
cd /tmp && c++ /usr/share/examples/hello.cpp -o hello && ./hello
craftos                  # CraftOS — оболочка CC: Tweaked, если нужен Lua
```

Компьютер не выключается сам: при выгрузке чанка или остановке сервера он запоминает, что был включён, и
загружается снова. Файлы компьютера хранятся в мире: `<мир>/computercraft/ccbaremetal/computer/<номер>`.

## Окно компьютера

Окно сделано как у продвинутого компьютера CC: Tweaked, только в аметисте: терминал в рамке CC, слева боковая
панель с кнопками. Окно занимает почти весь экран игры: столбцов и строк ровно столько, сколько помещается при
выбранном размере шрифта, а программы получают событие `term_resize`.

Рамка и боковая панель рисуются в масштабе интерфейса Minecraft и не меняются; размер шрифта меняет только текст —
пиксель шрифта занимает целое число пикселей экрана, так что пиксели всегда квадратные. В графическом режиме картинка показывается в самом большом целом масштабе,
который помещается в окно; дробный масштаб бывает, только если разрешение больше всего окна.

Кнопки на боковой панели (у каждой есть подсказка при наведении):

- **питание** — включить / выключить (как у CC);
- **перезагрузить**;
- **прервать программу** (как Ctrl+T в CC);
- **крупнее / мельче** — размер шрифта (меняется только текст, рамка остаётся прежней).

Над рамкой — номер компьютера и размер терминала (в графическом режиме — разрешение, число цветов и текущий
трафик экрана), а также короткие сообщения вроде «Скопировано символов: N».

## Клавиши

| Действие | Клавиши |
|---|---|
| Копировать выделение | **Ctrl+Shift+C** (или Ctrl+Insert; Ctrl+C — когда что-то выделено) |
| Вставить | **Ctrl+Shift+V** (или Ctrl+V, Shift+Insert, средняя кнопка мыши) |
| Выделить | перетаскивание мышью; двойной щелчок — слово, тройной — строка; Ctrl+Shift+A — всё |
| ПКМ | копировать выделение или вставить, если ничего не выделено |
| Прокрутка истории (2000 строк) | колесо мыши, Shift+PgUp/PgDn, Shift+Home/End |
| Размер шрифта | Ctrl+'+' / Ctrl+'-' / Ctrl+0 (авто), Ctrl+колесо, кнопки «+» / «−» на боковой панели |
| Прервать программу | Ctrl+C |
| Завершить (программы CraftOS) | удерживать Ctrl+T секунду |
| Перезагрузить / выключить | удерживать Ctrl+R / Ctrl+S секунду |

Горячие клавиши работают в любой раскладке (проверяется и код клавиши, и её физическое место). При копировании над
рамкой появляется «Скопировано символов: N».

Если программа сама использует мышь (например, CraftOS), выделение делается с зажатым Shift. Полноэкранные
программы (`edit`, `more`) работают на отдельном экране: после выхода возвращается то, что было в консоли, а
колесо мыши в них работает как стрелки.

Вставка в программы, которые это поддерживают (`edit`), приходит одним блоком (режим bracketed paste, как в
терминалах Linux), поэтому отступы вставленного кода не «съезжают». Программы могут и сами класть текст в ваш
буфер обмена (так делает Ctrl+C в `edit`) — над рамкой появится «Скопировано символов: N».

## Перенос файлов с компьютера

Файлы и папки можно перетащить в окно компьютера прямо из файлового менеджера (как в CC: Tweaked): они попадут в
текущую папку оболочки (или запущенной программы) с правами того, кто сидит за компьютером. Если такие файлы уже
есть, окно спросит, заменить ли их. Предел размера за раз — `upload_max_kb` в [настройках](08-config.md) (16 МБ). Программы (модули WebAssembly и скрипты с `#!`) приходят
исполняемыми, так что папка с программой, собранной на ПК, запускается сразу.

## Вход в систему

При каждом включении (и после `exit`) появляется приглашение `имя-компьютера login:`. Пользователь из установщика
состоит в группе `wheel` и может всё через `sudo`; учётная запись `root` есть всегда. Компьютеры, созданные до
появления установщика, сохраняют пользователя `user`: пока у него нет пароля, они входят в систему сами. Подробнее о
пользователях — в [разделе 3](03-system.md#пользователи-и-права).
